# 王宝煲音频按钮播放器

在bilibili活动、隶属于北立交桥妖精管理局的虚拟主播王宝煲的音频播放按钮网站，支持音频缓存、循环播放、随机播放等功能。

**项目演示**：[https://wangbaobao.moe/](https://wangbaobao.moe/)

## 项目结构

```text
bao-button/
├── index.html             # 页面结构
├── app.js                 # 音频播放与页面交互
├── styles.css             # 界面样式与响应式布局
├── 内容/                  # 集中维护的内容素材
│   ├── 音频/              # 按分类目录组织音频
│   ├── 表情包/            # 表情包原图
│   └── ED记录.csv         # ED 记录
├── public/                # 界面图片、图标及厨房素材
├── src/
│   ├── audio/             # 音频缓存与预加载
│   ├── config/            # 音频源与其他按钮配置
│   ├── info/              # 情报各功能的显示逻辑
│   └── ui/                # 时钟、导航和页面协调
├── scripts/               # 内容生成工具
├── test/                  # 自动化检查
├── .github/               # 自动检查与发布流程
└── LICENSE                # 代码许可证
```

前端负责页面展示与交互。音频、ED 和表情包以静态资源提供；目前数据、厨房统计及开播预测读取独立数据服务。本仓库不包含该服务的程序或数据库。

内容生成工具从“内容”目录整理音频分类、文件清单、ED 数据与表情包缩略图。生成文件与发布产物无需手动维护，也不提交到仓库。

## 功能说明

- **煲按钮**：分类浏览与播放音频，支持随机播放、停止所有和洗脑循环。
- **煲情报**：查看直播相关数据、ED 记录、表情包分享库、垫饭煲厨房及开播预测。
- ED 支持日期、歌名和歌手检索，点击记录可复制歌名。

界面使用简体中文，时间统一按北京时间显示；歌曲名称等内容保留原文。

## 内容与配置

- **音频**：分类来自目录，按钮名称来自文件名，排序编号不会显示在按钮上。
- **表情包**：从素材目录自动整理清单，并生成缩略图。
- **ED**：集中保存在 CSV 表格中，日期和歌手允许留空。
- **其他按钮与音频源**：使用独立配置，便于与页面交互逻辑分开维护。

## 性能与数据存储

音频采用受控并发预加载，并通过浏览器缓存减少重复下载。表情包使用缩略图与分批显示，降低一次性加载原图的开销。

浏览器会保存音频缓存及音频源选择等本地设置；清除站点数据后，这些缓存和设置也会被移除。情报内容来自独立数据服务，不应将本站理解为所有功能均离线运行。

## 常见问题

### 首次打开为什么需要加载？

网站会尝试预加载音频。首次访问的速度受网络和设备影响，有效缓存可减少后续访问的下载量。

### 音频或图片更新后没有变化怎么办？

先确认内容更新已成功发布，再尝试刷新页面；必要时清除该站点的浏览器缓存后重试。

### 为什么部分情报暂时不可用？

相关功能依赖独立数据服务，服务状态、连接情况或采集延迟都可能影响显示。

### ED 可以只填写歌名吗？

可以。日期和歌手可以留空，页面会显示“未录入”。

### 为什么 GIF 缩略图不动？

列表使用静态封面以保持浏览稳定，打开原图后查看动图。

### 开播预测代表确定的开播安排吗？

不代表。预测仅供娱乐，并非主播日程或承诺。
